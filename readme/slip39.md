## SLIP-0039 library

The SLIP-0039 library implements Shamir's secret sharing for mnemonic codes, as defined by [SLIP-0039](https://github.com/satoshilabs/slips/blob/master/slip-0039.md) (the backup scheme used by Trezor).
A master secret is split into several mnemonics (shares) and only some of them are needed to recover it. It allows you to:
- Generate share mnemonics from words number (random master secret) or from a master secret
- Recover the master secret (i.e. the BIP-0032 seed) from share mnemonics
- Extend a backup, i.e. generate a new set of share mnemonics from existing ones
- Validate a share mnemonic
- Encode/Decode a single share

SLIP-0039 uses a two-level scheme:
- The master secret is split into groups, and a *group threshold* number of groups is needed to recover it
- Each group is split into members, and a *member threshold* number of members is needed to recover the group

For example, with a group threshold of 2 and groups `[(1, 1), (3, 5)]`, the master secret can be recovered with the share of the first group plus 3 of the 5 shares of the second group.
For a basic *T*-of-*N* scheme, a single group shall be used (i.e. a group threshold of 1 and groups `[(T, N)]`).

The master secret can optionally be protected by a passphrase, which shall only contain printable ASCII characters. Like BIP-0039, any passphrase leads to a valid master secret, since there is no way to verify it.

**NOTE:** SLIP-0039 is not compatible with BIP-0039. The master secret is directly used as the BIP-0032 seed, so it can be passed to the `FromSeed` method of the BIP-0032 and BIP-0044 classes.

### Mnemonic generation

The `Slip39MnemonicGenerator` class is constructed with the sharing scheme:
- `group_threshold`: number of groups needed to recover the master secret (default: 1)
- `groups`: list of `(member threshold, member count)`, one for each group (default: `[(1, 1)]`, i.e. a single share)
- `extendable`: extendable backup flag (default: `True`). If set, the identifier is not used to encrypt the master secret, so that more sets of shares can be created for the same master secret
- `iteration_exponent`: PBKDF2 iteration exponent, the total number of iterations is 10000 * 2^exponent (default: 1)

There can be up to 16 groups with up to 16 members each. A group with member threshold 1 shall have a single member.

The share mnemonics can be generated by specifying the words number (in this case a random master secret will be used) or directly by specifying the master secret (at least 16 bytes, with an even length).
The result is a list of share mnemonics for each group.

Supported words number:

|Words number|Master secret length|Enum|
|---|---|---|
|20|128-bit|`Slip39WordsNum.WORDS_NUM_20`|
|33|256-bit|`Slip39WordsNum.WORDS_NUM_33`|

Other master secret lengths result in different mnemonic lengths (e.g. a 512-bit master secret results in 59 words).

Only English is supported, since SLIP-0039 doesn't define other languages.

**Code example**

    import binascii
    from bip_utils import Slip39MnemonicGenerator, Slip39WordsNum

    # Basic 2-of-3 scheme with a random 128-bit master secret
    groups = Slip39MnemonicGenerator(groups=[(2, 3)]).FromWordsNumber(Slip39WordsNum.WORDS_NUM_20)
    # A list of Mnemonic objects for each group
    for mnemonic in groups[0]:
        print(mnemonic)

    # Two-level scheme from a specific master secret, protected by a passphrase:
    # 2 groups out of 3 are needed, the first one with a single share, the others with 2-of-3 and 3-of-5 shares
    master_secret = binascii.unhexlify(b"bb54aac4b89dc868ba37d9cc21b2cece")
    groups = Slip39MnemonicGenerator(group_threshold=2, groups=[(1, 1), (2, 3), (3, 5)]).FromMasterSecret(master_secret, "my_passphrase")
    for i, group in enumerate(groups):
        print(f"Group {i}:")
        for mnemonic in group:
            print(f"  {mnemonic}")

### Seed generation

The `Slip39SeedGenerator` class combines the share mnemonics to recover the master secret, that is the BIP-0032 seed.
The shares are checked and combined when constructing the class, so an exception is raised if they cannot be combined (e.g. if they are not enough or they belong to different sets). The passphrase is only needed to get the seed.

Duplicated shares are ignored and the order of the shares doesn't matter.

**Code example**

    from bip_utils import Bip44, Bip44Coins, Slip39SeedGenerator

    mnemonics = [
        "shadow pistol academic always adequate wildlife fancy gross oasis cylinder mustang wrist rescue view short owner flip making coding armed",
        "shadow pistol academic acid actress prayer class unknown daughter sweater depict flip twice unkind craft early superior advocate guest smoking",
    ]

    # Generate the seed, a single mnemonic can also be passed directly for 1-of-1 schemes
    seed_bytes = Slip39SeedGenerator(mnemonics).Generate("TREZOR")
    # Use it to construct a BIP-0044 object
    bip44_mst_ctx = Bip44.FromSeed(seed_bytes, Bip44Coins.BITCOIN)
    print(bip44_mst_ctx.PrivateKey().ToExtended())

### Backup extension

Shares with the extendable backup flag can be used to generate a new set of shares, with a different scheme, for the same wallet (e.g. to upgrade a single share to a 2-of-3 scheme, like Trezor does).
The encrypted master secret is recovered from the existing shares and split again with a new random identifier, so:
- The passphrase is not needed, and the new shares result in the same seed for any passphrase
- Shares of the two sets cannot be mixed when recovering the seed
- The extendable flag and the iteration exponent are kept from the existing shares (the ones specified when constructing `Slip39MnemonicGenerator` are ignored)

Shares without the extendable flag cannot be extended, since their identifier is used to encrypt the master secret.

**NOTE:** the existing shares remain valid, so extending a backup is not a way to revoke them.

**Code example**

    from bip_utils import Slip39MnemonicGenerator, Slip39SeedGenerator, Slip39WordsNum

    # Single share, protected by a passphrase
    mnemonic = Slip39MnemonicGenerator().FromWordsNumber(Slip39WordsNum.WORDS_NUM_20, "my_passphrase")[0][0]

    # Upgrade to a 2-of-3 scheme, without the passphrase
    groups = Slip39MnemonicGenerator(groups=[(2, 3)]).FromMnemonics(mnemonic)

    # Same seed
    assert Slip39SeedGenerator(groups[0][:2]).Generate("my_passphrase") == Slip39SeedGenerator(mnemonic).Generate("my_passphrase")

### Mnemonic validation

A single share mnemonic can be validated with the `Slip39MnemonicValidator` class (words, length, padding and checksum).
Like for the other mnemonic validators, `IsValid` returns a boolean, while `Validate` raises:
- `MnemonicChecksumError` if the checksum is not valid
- `ValueError` if the mnemonic is not valid

Whether a set of shares can be combined is checked by `Slip39SeedGenerator`.

**Code example**

    from bip_utils import MnemonicChecksumError, Slip39MnemonicValidator

    mnemonic = "duckling enlarge academic academic agency result length solution fridge kidney coal piece deal husband erode duke ajar critical decision keyboard"

    # Get if valid
    is_valid = Slip39MnemonicValidator().IsValid(mnemonic)

    # Validate the mnemonic by raising exceptions in case of errors
    try:
        Slip39MnemonicValidator().Validate(mnemonic)
    except MnemonicChecksumError:
        # Invalid checksum...
        pass
    except ValueError:
        # Invalid length, padding or words...
        pass

### Share encoding/decoding

A single share mnemonic can be decoded to a `Slip39Share` object, which contains all the share fields, and encoded back.
Thresholds and counts are the actual values (i.e. a group threshold of 2 means that 2 groups are needed).

**Code example**

    from bip_utils import Slip39MnemonicDecoder, Slip39MnemonicEncoder

    mnemonic = "duckling enlarge academic academic agency result length solution fridge kidney coal piece deal husband erode duke ajar critical decision keyboard"

    share = Slip39MnemonicDecoder().Decode(mnemonic)
    print(share.identifier)
    print(share.extendable)
    print(share.iteration_exponent)
    print(share.group_index)
    print(share.group_threshold)
    print(share.group_count)
    print(share.member_index)
    print(share.member_threshold)
    print(share.value)

    # Encode it back
    print(Slip39MnemonicEncoder().Encode(share))
